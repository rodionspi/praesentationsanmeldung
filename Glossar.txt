Kapselung in C# bedeutet, dass Daten und Methoden einer Klasse in einer Einheit zusammengefasst und der Zugriff auf die internen Daten kontrolliert wird.

Warum Kapselung?
Bessere Kontrolle über Klassenelemente (verringert die Möglichkeit, dass du selbst (oder andere) den Code durcheinanderbringst)
Felder können nur lesbar gemacht werden (wenn nur die get-Methode verwendet wird) oder nur schreibbar (wenn nur die set-Methode verwendet wird)
Flexibel: Der Programmierer kann einen Teil des Codes ändern, ohne andere Teile zu beeinflussen
Erhöhte Datensicherheit

In C# ist es möglich, Felder und Methoden von einer Klasse zur anderen zu erben. Wir gruppieren das "Vererbungskonzept" in zwei Kategorien:

Abgeleitete Klasse (Kind) – die Klasse, die von einer anderen Klasse erbt
Basisklasse (Elternteil) – die Klasse, die von geerbt wird

Polymorphie bedeutet in der Programmierung „Vielgestaltigkeit“ und beschreibt die Fähigkeit von Objekten oder Methoden, je nach Kontext unterschiedliche Formen oder Verhalten anzunehmen.

Statische Polymorphie (Compile‑Time)
Bei statischer Polymorphie entscheidet der Compiler bereits beim Übersetzen, welche Methode ausgeführt wird. Dies geschieht durch Methodenüberladung, also mehrere Methoden mit gleichem Namen, aber unterschiedlichen Parametern



class Rechner
{
    public int Add(int a, int b) => a + b;
    public double Add(double a, double b) => a + b;
}
var r = new Rechner();
Console.WriteLine(r.Add(3, 4));      // ruft Add(int, int) auf
Console.WriteLine(r.Add(3.5, 1.2));  // ruft Add(double, double) auf




Dynamische Polymorphie (Runtime)
Dynamische Polymorphie tritt auf, wenn eine abgeleitete Klasse eine Methode der Basisklasse überschreibt. Welche Methode ausgeführt wird, entscheidet sich erst zur Laufzeit anhand des tatsächlichen Objekttyps



class Tier
{
    public virtual void MachLaut() => Console.WriteLine("Ein Tier macht einen Laut.");
}

class Hund : Tier
{
    public override void MachLaut() => Console.WriteLine("Der Hund bellt.");
}
Tier t = new Hund();
t.MachLaut();   // Ausgabe: "Der Hund bellt." (Laufzeitentscheidung)

Was virtual bedeutet
Mit virtual kennzeichnet eine Basisklasse eine Methode, Eigenschaft oder ein Ereignis als überschreibbar.

Was override bedeutet
override wird in einer abgeleiteten Klasse verwendet, um eine virtual (oder abstract) Methode der Basisklasse zu ersetzen.


Was ist eine abstrakte Klasse?
Eine abstrakte Klasse (gekennzeichnet durch das Schlüsselwort abstract) dient als reine Vorlage für andere Klassen.
Keine Instanziierung: Sie können kein Objekt direkt von einer abstrakten Klasse erstellen (z. B. new Tier() ist nicht erlaubt).
Gemeinsamer Code: Sie kann sowohl fertig implementierte Methoden und Eigenschaften als auch unvollständige (abstrakte) Teile enthalten.

Was ist eine abstrakte Methode?
Eine abstrakte Methode ist eine Methode ohne Rumpf (sie hat keinen Code-Inhalt in geschweiften Klammern {}).
Sie existiert nur in abstrakten Klassen.
Zwang zur Implementierung: Jede Klasse, die von der abstrakten Klasse erbt, muss diese Methode zwingend mit dem Schlüsselwort override mit Leben füllen.

Ein Interface (Schnittstelle) in C# ist wie ein Vertrag oder eine Checkliste für Klassen.Es definiert nur, was eine Klasse tun können muss, aber absolut nicht, wie sie es tut. Ein Interface enthält standardmäßig keinerlei Code – keine Variablen, keine fertigen Methoden und keinen Programmiercode.

Die Implementation (oft auch Implementierung genannt) ist der konkrete Prozess oder das Ergebnis des Umsetzens einer Idee, eines Plans, einer Spezifikation oder eines Konzepts in die Realität – oder in der Informatik: in funktionierenden Programmcode.

Ein Enum (steht kurz für Enumeration, auf Deutsch: Aufzählung) ist in C# ein spezieller Datentyp, mit dem du eine Liste von benannten Konstanten erstellen kannst.

class Program
{
  enum Level
  {
    Low,
    Medium,
    High
  }
  static void Main(string[] args)
  {
    Level myVar = Level.Medium;
    Console.WriteLine(myVar);
  }
}

EF Core (Entity Framework Core) ist eine ORM-Bibliothek (Object-Relational Mapper) von Microsoft für .NET. Sie übersetzt zwischen zwei Welten, die normalerweise nicht zusammenpassen

Ein Endpoint ist ganz allgemein: eine Kombination aus URL-Pfad + HTTP-Methode, die am Ende tatsächlich Code ausführt und eine Response liefert.

Ein Controller ist in ASP.NET Core eine Klasse, die mehrere zusammengehörige Endpoints als Methoden gruppiert — genannt Actions.

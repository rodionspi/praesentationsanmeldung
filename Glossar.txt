DLL steht für Dynamic Link Library, auf Deutsch etwa dynamisch eingebundene Bibliothek. Gemeint ist eine Datei mit der Endung .dll, die fertig kompilierten Code enthält, den andere Programme benutzen können.

Eine Migration ist eine Bauanleitung für die Datenbank. Sie beschreibt Schritt für Schritt, wie die Datenbank geändert werden muss, damit sie zu deinem C#-Code passt

Eigenschaft ist das deutsche Wort für Property in C#. Gemeint ist ein Wert, den ein Objekt hat, also ein Merkmal, das das Objekt beschreibt.

Build (englisch to build, „bauen“) ist der Vorgang, bei dem aus deinem Quellcode ein lauffähiges Programm entsteht.
